# host_slave_send：CIPMODE + CIPSEND 专题测试

Windows 双线程模拟主机与从机，**只覆盖** 透传 / 定长 SEND 相关交互。完整场景与契约见 [PLAN.md](PLAN.md)。

## 如何运行

```bash
cd lw_at/tests/system/host_slave_send
make run
```

需要 Windows + `gcc`。退出码 0 表示全部检查通过。

## 与其它目录

| 目录 | 用途 |
| --- | --- |
| `host_slave_win` | 双端通测（多命令、噪声、压力）；仅无参流式 CIPSEND |
| `host_slave_send`（本目录） | SEND 模式切换专题（定长 + 流式 + 进出边界） |
| `host` / `lw_at_core` | 单线程快速回归；core 含 C14 定长 |
| `async_script` | 虚拟时间逐步脚本 |

## 关键契约摘要

| 项 | 约定 |
| --- | --- |
| 进入提示 | `\r\nOK\r\n>\r\n`（`>` 单独成行） |
| 进入清环 | 与 `CIPSEND` 同行粘连的载荷会被丢弃；须等 `>` 后再发（A-01/A-02） |
| 定长收满 | 普通 `\r\nOK\r\n`；中止（`+++` 若允许 / `data_exit`）为 `\r\nERROR\r\n` |
| 流式 `+++` 退出 | 排空后回命令模式并自动回 `\r\nOK\r\n` |
| 流式环溢出 | **不**回 ERROR，仅丢字节；命令模式溢出回 ERROR（B-01 / B-CMD） |

本套件对结果码使用**精确全文匹配**；`host_enter_*` 失败则跳过该场景后续步骤。

## 如何阅读控制台输出

启动时将控制台设为 UTF-8。主要标记：

| 标记 | 含义 |
| --- | --- |
| `【主机→从机】发送` | 主机写下行 |
| `【从机→主机】应答` | 从机上行回包 |
| `【主机】…` | 主机侧动作说明（进流式/定长、发 `+++` 等） |
| `【链路】安静窗` | 观察期内从机无上行 |
| `【断言】通过/失败` | 检查结果 |

结束时打印断言次数与失败场景数。
