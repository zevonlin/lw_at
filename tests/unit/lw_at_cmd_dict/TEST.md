# lw_at_cmd_dict 模块测试

本目录对 [`lw_at_cmd_dict.c`](../../../src/lw_at_cmd_dict.c) 做单元测试，仅链接命令字典模块本身，不涉及字节流接收或应答格式。

注册失败在整机路径上的可见表现（例如 `lw_at_cmd_register` 返回错误后无法处理命令）见 `lw_at_core` 与 `host`。

## 如何运行

```bash
cd lw_at/tests/unit/lw_at_cmd_dict
make run
```

进程退出码为 0 表示全部检查通过。

## 模块职责（测试背景）

命令字典维护已注册的 AT 命令集合，并提供按名查找：

1. 用户可以提供多张静态命令表，通过多次注册挂到内部链表上（典型用法是不同业务模块各自提供一张表）。
2. 注册时检查非法配置并拒绝：空指针、空表、条目名为 `NULL`、同一张表内命令名重复、与已注册表跨表重名、同一表节点被重复注册（防止链表成环）。
3. 查找按命令名**精确匹配且区分大小写**。协议中的裸 `AT` 对应名字为空字符串 `""` 的表项。

配置侧常见失误：表内复制粘贴导致重名、两个模块各自注册了同名命令、把表节点放在栈上临时变量、`deinit` 之后未 `reset` 又重复挂链。交互侧常见情况：查找未注册名、主机发送小写命令名、忘记为裸 `AT` 注册空名项。

## 测试项一览

| 编号 | 测试项 | 测试原因 | 预期结果 |
| --- | --- | --- | --- |
| D01 | `reset` 之后查找为空 | 上电或反初始化后字典应干净 | 查找任意名字均返回空指针 |
| D02 | 对空指针调用注册 | 接口防护 | 返回参数错误 |
| D03 | 表内命令数组指针为空，或条目数等于 0 | 非法表配置 | 返回参数错误 |
| D04 | 某一条目的 `name` 为 `NULL` | 配置遗漏 | 返回参数错误 |
| D05 | 同一张表内出现两个相同命令名 | 用户表写错 | 返回参数错误 |
| D06 | 正常注册后按名查找 | 主路径 | 注册成功；`find("+ECHO")` 返回与注册时相同的条目指针 |
| D07 | 查找区分大小写 | 主机可能误发小写 | `find("+echo")` 返回空指针 |
| D08 | 查找从未注册的名字 | 未知命令 | 返回空指针 |
| D09 | 查找传入 `NULL` | 非法入参 | 返回空指针 |
| D10 | 注册并查找空名字 `""` | 裸 `AT` 的协议要求 | 空名项可注册，且 `find("")` 命中 |
| D11 | 先后注册两张不同命令表 | 多模块挂接 | 两张表中的命令都能被查到 |
| D12 | 第二张表与已注册表出现同名命令 | 模块间命名冲突 | 第二次注册失败；第一张表原有命令仍可查到 |
| D13 | 同一表节点注册两次 | 防止链表成环 | 第二次注册返回状态错误 |
| D14 | 以链表头部插入方式挂接后多表共存 | 链表挂接顺序不应影响精确查找 | 先注册与后注册的命令均可按名找到 |
| D15 | `reset` 清空整条链表 | `deinit` / 重新初始化 | `reset` 之后旧命令查找失败 |
| D16 | `reset` 之后再次注册 | 生命周期可重复 | 再次注册与查找成功 |

## 如何阅读控制台输出

每个用例打印标题、`>>`（操作）、`<<`（观测结果）以及 `[PASS]` / `[FAIL]`。程序结束时汇总 `checks` 与 `failed`。
